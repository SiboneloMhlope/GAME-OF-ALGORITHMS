# 🎮 Game of Algorithms

### Making Data Structures and Algorithms more interactive, one algorithm at a time.

**Game of Algorithms** is an interactive educational web project developed as a first-semester Computer Science group project.

The project aims to make learning fundamental sorting algorithms more engaging by transforming theoretical concepts into interactive, game-based experiences.

It currently features two sorting algorithm games:

- Bubble Sort
- Insertion Sort

## 🏆 Recognition & Achievement

This project achieved **1st place as the best project in our entire class**.

Following this achievement, our team was selected by the Computer Science Department to present Game of Algorithms at **BZ Hall during the Faculties' Career Expo**.

This provided an opportunity to showcase our work and demonstrate how interactive software can be used to support computer science education.

## 📖 Project Motivation

Understanding Data Structures and Algorithms can be challenging, particularly when concepts are introduced through theory and pseudocode alone.

This project was developed around the idea that learning can become more engaging when theoretical concepts are translated into interactive experiences.

As a visual learner, I found that interacting with algorithmic processes helped reinforce my understanding of how sorting algorithms work.

Game of Algorithms gave us an opportunity to explore that approach by combining fundamental computer science concepts with game-based learning.

## ✨ Features

### 1. Bubble Sort Game

An interactive game designed around the Bubble Sort algorithm.

It introduces learners to the fundamental logic behind Bubble Sort and provides guidance to help them understand the sorting process.

### 2. Insertion Sort Adventure

An interactive, gamified experience based on the Insertion Sort algorithm.

Gameplay elements include:

- Multiple levels.
- Countdown timer.
- Points and scoring.
- Lives system.
- Consecutive-correct streaks.
- Hints.
- High scores.
- Player profiles.
- Companion and reward system.
- Sound effects and background music.

The objective is to reinforce the logic of Insertion Sort through interaction and repetition.

## 🧠 Algorithms Covered

| Algorithm | Main Concept | Average Time Complexity |
|---|---|---|
| Bubble Sort | Comparing and swapping adjacent elements | O(n²) |
| Insertion Sort | Building a sorted sequence by inserting elements into their correct positions | O(n²) |

## 🚀 Running Locally

1. Clone the repository:

```bash
git clone https://github.com/SiboneloMhlope/GAME-OF-ALGORITHMS.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Explore the available games.

No backend installation or database configuration is required.
